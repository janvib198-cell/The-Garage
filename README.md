The Garage - Task Planner PWA

A dark-themed Progressive Web App (PWA) designed to organize work into focused garage bays and manage daily productivity effortlessly.

Live Demo:[https://janvib198-cell.github.io/The-Garage/](https://janvib198-cell.github.io/The-Garage/)

Features

Garage Bays:Categorize tasks into specialized focus areas (Bugatti, Porsche, Defender, Jaguar).
PWA Support:Installable directly on desktop and mobile devices.
Offline Access:Service Worker caching ensures functionality even without internet connection.
Auto-Save:Tasks automatically persist in local browser storage.

#Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6)
PWA: Service Workers (`sw.js`), Web App Manifest (`manifest.json`)
Hosting: GitHub Pages
